Deep Clone Detector

Welcome to Deep-Clone Detector!

  • This is a source code analysis tool for Java projects and assists you in detecting clones in your code as well as provide analysis and suggestions to help in the prevention of clones.

  • This application utilizes a novel feature extraction technique utilizing Adversarial Auto-encoders and provides you with an overall accuracy of over 85% for both syntax and semantic clones.

  • Within the code clone detection domain it is the first tool of its kind to prioritize analysis for clone prevention.

  • Refer to the instruction below to learn how to utilize the application.

Instructions

Follow these simple steps to achieve clone free code.

  1. Convert your java project to a zip file(or download your git repository as a zipped file)
  2. Navigate to the Upload page and upload the file and a insert a suitable name for future reference
  3. Click upload and wait a few seconds for the processing.
  4. Click on the button with the name of your project and select to view Detected Clones Clones
  5. Refer the Analytics page for analysis and prevention help
  6. Make the suggested changes in your code and re-upload to view your progress.
